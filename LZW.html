How to read the notation and dictionary
Notation: a single character such as A in the Output column stands for its numeric code, 65. A learned phrase uses a code such as <256>. The computer sends numbers in both cases.
The dictionary: the encoder and decoder each start with the same 256 single-byte entries. Both build their own new entries. This example does not send the completed dictionary.
Visible whitespace: ␠ = space, ↵ = newline, ⇥ = tab. \xNN shows a non-printable or non-ASCII byte in hexadecimal. Non-ASCII characters can use several UTF-8 bytes.
